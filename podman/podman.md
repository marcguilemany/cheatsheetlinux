\begin{Buscando Imagenes}           % Start of the document

\item $\color{blue}{\textsf{podman images}}$ => Lista todas las imagenes locales
\item $\color{blue}{\textsf{podman history image:tag}}$ => Muestra información de como se contruyó la imagen
\item $\color{blue}{\textsf{podman login registryURL -u username [-p password]}}$ => Hace el login al registry remoto

\end{Buscando Imagenes}
