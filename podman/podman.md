Comandos de Podman



##Buscando Imagenes
$\color{blue}{\textsf{podman images}}$ => Lista todas las imagenes locales
$\color{blue}{\textsf{podman history image:tag}}$ => Muestra información de como se contruyó la imagen
$\color{blue}{\textsf{podman login registryURL -u username [-p password]}}$ => Hace el login al registry remoto
